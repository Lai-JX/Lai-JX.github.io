    Kimi K3 的 Gated MLA：从公式、维度到矩阵吸收¶

    本文介绍 Kimi K3 技术报告中的 Gated MLA。它保留 MLA 的低维 KV 表示，在注意力输出投影之前增加一个由当前 token 控制的逐通道 sigmoid gate。

    本文统一使用行向量：token 特征位于最后一维，线性映射写成 \(y=xW\)。公式中的矩阵采用 [in, out] 形状；PyTorch 的 nn.Linear.weight 保存其转置，即 [out, in]。

    0. 先记住一句话¶

    Gated MLA 的核心公式是：

    \[ \boxed{ y_t= \left[ \sigma(x_tW^G)\odot\widetilde o_t \right]W^O } \]

    可以把它记成：

    \[ \boxed{ \text{MLA 决定“读出什么”，Gate 决定“让哪些输出通道通过”。} } \]

    Gate 不直接修改注意力 logits 或 softmax 权重，而是调制 softmax attention 已经读出的结果。

    1. 行向量和维度约定¶

    设：

    • \(d\)：模型隐藏维度；
    • \(H\)：注意力头数；
    • \(d_v\)：每个头的 value 输出维度；
    • \(m=Hd_v\)：全部头拼接后的维度；
    • \(x_t\in\mathbb{R}^{1\times d}\)：当前 token 的层输入；
    • \(\widetilde o_t\in\mathbb{R}^{1\times m}\)：多头注意力结果拼接后、输出投影前的向量；
    • \(g_t\in(0,1)^{1\times m}\)：逐通道 gate；
    • \(y_t\in\mathbb{R}^{1\times d}\)：注意力模块输出。

    在本文的行向量约定下：

    \[ \underbrace{g_t}_{1\times m} =\sigma\left( \underbrace{x_t}_{1\times d} \underbrace{W^G}_{d\times m} \right), \]
    \[ \underbrace{y_t}_{1\times d} = \left( \underbrace{g_t}_{1\times m} \odot \underbrace{\widetilde o_t}_{1\times m} \right) \underbrace{W^O}_{m\times d}. \]

    对应 PyTorch：

    g_proj = nn.Linear(d, m, bias=False)  # g_proj.weight: [m, d]
o_proj = nn.Linear(m, d, bias=False)  # o_proj.weight: [d, m]

gate = sigmoid(g_proj(x))             # 等价于 sigmoid(x @ W_G)
y = o_proj(gate * attn_output)        # 等价于 (gate ⊙ attn_output) @ W_O

    Kimi K3 的实际维度¶

    官方配置给出：

    \[ d=7168,\qquad H=96,\qquad d_v=128, \]

    所以：

    \[ m=Hd_v=96\times128=12288. \]

    因此 Kimi K3 Gated MLA 中：

    \[ W^G\in\mathbb{R}^{7168\times12288}, \qquad W^O\in\mathbb{R}^{12288\times7168}. \]

    这说明 gate 的通道数不一定等于模型隐藏维度 \(d\)。它对应的是输出投影之前的全部 head-value 通道。

    2. 从普通 MLA 到 Gated MLA¶

    2.1 普通 MLA¶

    先把每个头的注意力过程抽象为：

    \[ P_{t,i}=\operatorname{Softmax} \left( \frac{q_{t,i}K_i^T}{\sqrt{d_k}}+M_t \right), \]
    \[ o_{t,i}=P_{t,i}V_i \in\mathbb{R}^{1\times d_v}, \]

    其中 \(M_t\) 是 causal mask。把所有头的输出横向拼接：

    \[ \widetilde o_t= \operatorname{Concat}(o_{t,1},\ldots,o_{t,H}) \in\mathbb{R}^{1\times m}. \]

    普通 MLA 的输出为：

    \[ y_t=\widetilde o_tW^O. \]

    2.2 加入逐通道 gate¶

    Kimi K3 增加一条由当前输入产生的门控分支：

    \[ g_t=\sigma(x_tW^G). \]

    再在输出投影之前逐元素相乘：

    \[ \widetilde o_t^{\,gated}=g_t\odot\widetilde o_t, \]
    \[ y_t=\widetilde o_t^{\,gated}W^O. \]

    Gate 具有三个特征：

    • input-dependent：不同 token 的 \(x_t\) 不同，因此 gate 不同；
    • channel-wise：每个输出通道有独立门值，而不是整层共用一个标量；
    • full-rank parameterization：使用一个从 \(d\) 到 \(m\) 的直接投影，而不是两个矩阵组成的低秩瓶颈。

    这里的 “full-rank” 指完整尺寸的直接参数化，并不保证训练后矩阵在数值意义上一定达到最大秩。

    3. Gate 具体加在哪里¶

                             ┌─> gate = sigmoid(x_t @ W_G) ───────────┐
当前输入 x_t ────────────┤                                         │
                         └─> Q/K/V → softmax attention ─> o_tilde ├─> 按通道相乘
                                                                  │
                                                                  ▼
                                                        output projection W_O
                                                                  │
                                                                  ▼
                                                                 y_t

    准确位置是：

    \[ \boxed{ \text{SDPA/MLA 输出之后，output projection 之前。} } \]

    它不是直接加在以下位置：

    • Q、K 或 V 投影上；
    • \(QK^T\) logits 上；
    • softmax attention probability 上；
    • KV latent 或 KV Cache 上；
    • output projection 之后。

    因此：

    \[ P_t=\operatorname{Softmax} \left( \frac{Q_tK^T}{\sqrt{d_k}}+M_t \right) \]

    本身没有被 gate 逐元素修改。Gate 调制的是 \(P_tV\) 产生的通道。

    4. Gate 控制的是什么¶

    假设某个 token 的部分 gate 为：

    \[ g_t=\begin{bmatrix} 0.02&0.95&0.60&0.01&\cdots \end{bmatrix}. \]

    那么 \(g_t\odot\widetilde o_t\) 表示：

    • 第一个通道被强烈衰减；
    • 第二个通道基本保留；
    • 第三个通道部分保留；
    • 第四个通道被强烈衰减。

    它并不是只做一个二元决定：

    当前 token 是否使用 MLA？

    更准确的理解是：

    当前 token 从全局上下文中读出的每个 head-value 通道，分别允许通过多少？

    因为 sigmoid 的输出位于 \((0,1)\)，有限输入下它通常执行连续衰减，而不是严格产生 0/1 开关。

    5. 为什么这种 gate 可能有效¶

    5.1 增加输入相关的非线性交互¶

    没有 gate 时，在注意力概率 \(P_t\) 已经确定后，从 value 到输出的主要路径是线性组合：

    \[ \widetilde o_t=P_tV, \qquad y_t=\widetilde o_tW^O. \]

    加入 gate 后：

    \[ y_t= \left[ \sigma(x_tW^G)\odot(P_tV) \right]W^O. \]

    当前输入 \(x_t\) 与 attention 读取结果之间出现了乘法交互，因此整个映射不再只是固定的线性 value/output 链。

    5.2 给“从哪里读”和“是否接收”分工¶

    Softmax 必须满足：

    \[ \sum_j P_{t,j}=1. \]

    即使某次读取对部分输出通道帮助很小，softmax 仍会把概率质量分配到某些历史位置。输出 gate 增加了一条独立控制路径：

    • softmax attention 决定从哪些位置读取；
    • output gate 决定读出的哪些通道进入后续网络。

    5.3 与 attention sink 的关系¶

    Attention sink（注意力汇）是指某些位置长期吸收较大的注意力概率，最常见的是序列开头的 BOS 或前几个 token。即使这些 token 的内容与当前预测关系不大，一些注意力头仍可能持续关注它们。

    一种直观理解是：softmax 要求每个 query 的注意力概率之和为 1。当某个注意力头没有特别需要读取的位置时，它也不能把全部概率都设为 0，于是可能把暂时“用不上的”概率集中到少数固定位置。这些位置就像注意力概率的汇点。较大的注意力权重因此不一定表示模型真正使用了该 token 的语义信息。

    《Gated Attention for Large Language Models》对多种 gated softmax-attention 结构进行了系统实验，发现 SDPA 后的 sigmoid gate 能改善训练稳定性和长上下文外推，并缓解 attention sink。该工作将收益主要归因于非线性和 query-dependent sparse gating。

    需要区分两件事：

    • Gate 不会在当前前向计算中直接改写已经得到的 \(P_t\)；
    • 但训练时整个网络会共同适配，实验证据表明门控模型最终学到的 attention sink 行为可以减弱。

    Kimi K3 技术报告引用了这一门控机制，但不能把通用 Gated Attention 论文中的所有消融结果都当作 Kimi K3 自身的独立 gate 消融。

    6. Gated MLA 与矩阵吸收的关系¶

    这一部分沿用《MLA 矩阵吸收算法详解》中的行向量约定。

    6.1 K 吸收不受影响¶

    MLA 把第 j 个历史 token 压缩成：

    \[ c_j=h_jW^{DKV}, \qquad c_j\in\mathbb{R}^{1\times r}. \]

    第 i 个头的内容 key 为：

    \[ k_{j,i}=c_jW_i^{UK}, \qquad W_i^{UK}\in\mathbb{R}^{r\times d_k}. \]

    注意力 score 可以改写为：

    \[ q_{t,i}k_{j,i}^T =q_{t,i}(c_jW_i^{UK})^T =\underbrace{q_{t,i}(W_i^{UK})^T}_{\widehat q_{t,i}}c_j^T. \]

    Gate 位于 attention 输出端，不进入 score 公式，所以 K 吸收完全不受影响。

    6.2 V 的 latent 聚合仍然成立¶

    第 i 个头原本需要：

    \[ o_{t,i} =\sum_jP_{t,i,j}v_{j,i} =\sum_jP_{t,i,j}c_jW_i^{UV}. \]

    利用分配律：

    \[ o_{t,i} =\left(\sum_jP_{t,i,j}c_j\right)W_i^{UV} =z_{t,i}W_i^{UV}, \]

    其中：

    \[ z_{t,i}=\sum_jP_{t,i,j}c_j \in\mathbb{R}^{1\times r}. \]

    因此仍然可以先用注意力权重聚合历史 latent，再只为当前 token 展开一次 value。无需为全部历史 token 物化或缓存完整 V。

    6.3 但 V 上投影不能再与输出投影静态合并¶

    这是容易忽略的区别。

    没有 gate 时，把 \(W^O\) 按头分为 \(W_i^O\in\mathbb{R}^{d_v\times d}\)，可以写成：

    \[ y_t =\sum_i z_{t,i}W_i^{UV}W_i^O. \]

    于是能够预先计算静态矩阵：

    \[ B_i=W_i^{UV}W_i^O. \]

    加入 gate 后，把 \(g_t\) 按头切成 \(g_{t,i}\in(0,1)^{1\times d_v}\)：

    \[ y_t =\sum_i \left[ (z_{t,i}W_i^{UV})\odot g_{t,i} \right]W_i^O. \]

    使用对角矩阵表示逐元素乘法：

    \[ y_t =\sum_i z_{t,i}W_i^{UV} \operatorname{Diag}(g_{t,i}) W_i^O. \]

    由于 \(\operatorname{Diag}(g_{t,i})\) 对每个 token 都不同，它夹在 \(W_i^{UV}\) 与 \(W_i^O\) 之间，因此不能提前形成固定的 \(W_i^{UV}W_i^O\)。

    结论是：

    MLA 优化 Gated MLA 中是否仍成立
    只缓存低维 KV latent 是
    K 上投影吸收到当前 Q 是
    先聚合 latent，再展开当前 V 是
    不物化全部历史 K/V 是
    将 \(W_i^{UV}\) 与 \(W_i^O\) 静态合并 否，动态 gate 位于两者之间

    所以“Gated MLA 不影响 MLA 吸收”并不够精确。更准确的说法是：

    \[ \boxed{ \text{K 吸收和 latent 聚合保留；V-up 与 output projection 的静态融合被 gate 阻断。} } \]

    7. Gate 自己能否被吸收到输出投影¶

    行向量公式为：

    \[ y_t=(g_t\odot\widetilde o_t)W^O =\widetilde o_t\operatorname{Diag}(g_t)W^O. \]

    形式上可以定义：

    \[ W_{t}^{O\prime}=\operatorname{Diag}(g_t)W^O. \]

    但：

    \[ g_t=\sigma(x_tW^G) \]

    随 token 改变，所以 \(W_t^{O\prime}\) 也是动态矩阵。若每个 token 都显式生成它，成本通常远高于直接逐元素相乘，因此不能像静态模型权重那样离线吸收。

    Gate 通常也不能移动到输出投影之后，因为一般有：

    \[ (g_t\odot\widetilde o_t)W^O \ne g_t\odot(\widetilde o_tW^O), \]

    而且左右两侧的通道维度甚至可能不同：左侧 gate 是 \(m\) 维，投影结果是 \(d\) 维。

    实际执行顺序仍然是：

    attention output
    → sigmoid gate
    → elementwise multiply
    → output projection

    Sigmoid 和逐元素乘法可以融合进 kernel，但 \(x_tW^G\) 的投影计算仍然存在。

    8. 是否增加 KV Cache¶

    Gate 只依赖当前 token 的 \(x_t\)，并只服务于当前 attention 输出：

    \[ g_t=\sigma(x_tW^G). \]

    生成下一个 token 时不需要再次使用过去的 \(g_t\)，所以 gate 不需要写入 KV Cache。

    因此：

    \[ \boxed{ \text{Gated MLA 的 gate 不改变 MLA Cache 的渐近大小。} } \]

    它既不会进一步压缩 KV latent，也不会因为逐通道门控而增加随序列长度增长的缓存。

    Kimi K3 的 NoPE¶

    Kimi K3 的所有 MLA 层使用 NoPE：Q、K 不施加显式位置编码。其设计分工是：

    • KDA 层提供位置敏感、近期敏感的序列混合；
    • MLA 层提供不受局部窗口限制的全局内容交互；
    • NoPE 避免扩展上下文时重新调整 RoPE base 或 YaRN 参数。

    需要注意，NoPE 和 output gate 是两个独立设计：

    \[ \boxed{ \text{Gated MLA：在输出端增加 gate；} \qquad \text{NoPE MLA：Q/K 不施加位置编码。} } \]

    官方参考代码仍保留名为 qk_rope_head_dim、q_rot、k_rot 的兼容性字段和分支，但断言 use_nope，并将 rotary_emb 设为 None；这些名称不代表实际执行了旋转。

    9. 参数量与计算代价¶

    Gate 矩阵为：

    \[ W^G\in\mathbb{R}^{d\times m}. \]

    忽略 bias 后，每个 Gated MLA 层新增：

    \[ dm \]

    个参数，并为每个 token 增加一次 \(x_tW^G\) 投影，以及 sigmoid 和逐元素乘法。

    对 Kimi K3：

    \[ d=7168,\qquad m=12288, \]

    所以每个 Gated MLA 层的 gate 投影包含：

    \[ 7168\times12288 =88{,}080{,}384 \]

    个参数，约为 8810 万。24 个 Gated MLA 层合计约 21.1 亿 gate 参数。

    Gate 投影的单 token 计算复杂度为：

    \[ O(dm), \]

    它不依赖历史长度 \(T\)。因此 gate 会增加固定的逐 token 投影成本，但不会改变 MLA attention 关于序列长度的复杂度，也不会破坏其 KV Cache 压缩优势。

    一个训练实现细节¶

    Kimi K3 技术报告还说明，为修正 flash attention 中的有偏舍入误差，训练时将 attention output 保持为 FP32。这样会使输出 tile 的片上占用翻倍，因此团队重新设计了训练 kernel 的缓冲区重叠方式。这个 FP32 选择是数值与 kernel 实现问题，不是 gate 数学定义的一部分。

    10. 为什么与 KDA 混合¶

    Kimi K3 使用层级混合注意力。每个常规 block 包含：

    \[ \boxed{ 3\text{ 个 KDA 层}+1\text{ 个 Gated MLA 层} } \]

    并在 backbone 末尾额外放置一个 Gated MLA 层，确保最后一层执行全局 attention。官方模型共有：

    • 69 个 KDA 层；
    • 24 个 Gated MLA 层；
    • 合计 93 个 attention 层。

    两类层的作用可以粗略理解为：

    模块 历史状态 主要作用
    KDA 固定大小的递归状态 以线性复杂度持续混合长序列信息
    Gated MLA 随序列增长的压缩 latent Cache 周期性执行完整的全局 token-to-token attention
    Output gate 当前 token 的临时激活 调制全局读取结果的各个输出通道

    典型周期为：

    KDA → KDA → KDA → Gated MLA

    需要注意：Gated MLA 仍然是全局 softmax attention；MLA 压缩的是 KV Cache，并没有把 attention 的序列复杂度变成线性。

    11. 接近官方实现的 PyTorch 伪代码¶

    class GatedMLA(nn.Module):
    def __init__(self, d, num_heads, d_v):
        super().__init__()
        self.num_heads = num_heads
        self.d_v = d_v
        m = num_heads * d_v

        # 省略 MLA 的 Q/K/V 与 latent 投影
        self.g_proj = nn.Linear(d, m, bias=False)
        self.o_proj = nn.Linear(m, d, bias=False)

    def forward(self, x, cache):
        # MLA/SDPA 输出，尚未执行 output projection
        head_output = mla_attention(x, cache)       # [B, T, H, d_v]
        attn_output = head_output.reshape(          # [B, T, H*d_v]
            x.shape[0], x.shape[1], -1
        )

        gate = torch.sigmoid(self.g_proj(x))        # [B, T, H*d_v]
        gated_output = attn_output * gate           # 逐通道门控
        y = self.o_proj(gated_output)                # [B, T, d]
        return y

g = self.g_proj(hidden_states).sigmoid()

attn_output = self.o_proj(attn_output)

    12. 普通 MLA 与 Kimi K3 Gated MLA 对比¶

    项目 普通 MLA Kimi K3 Gated MLA
    KV 联合压缩 有 有
    KV Cache 低维 latent 基本相同，gate 不入 Cache
    Attention 权重 softmax softmax，本次前向不被 gate 直接修改
    输出公式 \(y_t=\widetilde o_tW^O\) \(y_t=[\sigma(x_tW^G)\odot\widetilde o_t]W^O\)
    Gate 粒度 无 token-dependent、channel-wise
    Gate 参数化 无 从 \(d\) 到 \(Hd_v\) 的直接 full-rank 投影
    K 吸收 支持 支持
    latent 上的 V 聚合 支持 支持
    \(W^{UV}\) 与 \(W^O\) 静态融合 支持 被动态 gate 阻断
    位置编码 取决于模型 Kimi K3 中为 NoPE
    额外计算 无 gate 成本 一次 gate 投影、sigmoid 和逐元素乘法

    13. 常见误解¶

    误解 1：Gate 控制关注哪些历史 token¶

    不是直接控制。历史位置选择仍由 softmax attention 完成；gate 控制的是读取结果的输出通道。

    误解 2：Gate 作用于模型隐藏维度 \(d\)¶

    不一定。Kimi K3 中 gate 作用于输出投影前的 \(Hd_v=12288\) 个通道，而模型隐藏维度是 \(7168\)。

    误解 3：Full-rank 表示矩阵一定满秩¶

    这里主要指不使用低秩瓶颈的直接投影参数化，不是对训练后数值秩的保证。

    误解 4：Gate 可以和输出投影离线合并¶

    不可以。Gate 是由当前 \(x_t\) 动态产生的激活，不是固定权重。

    误解 5：Gated MLA 完全不影响 V 吸收¶

    需要分两层理解：先聚合 latent 再展开当前 V 仍然成立，但 gate 会阻止 V 上投影与 output projection 的静态矩阵融合。

    误解 6：NoPE 就是不具备位置信息¶

    NoPE 只表示 MLA 的 Q/K 不显式应用位置编码。整个 Kimi K3 网络仍通过相邻的 KDA 层获得位置敏感和近期敏感的信息混合。

    14. 核心理解¶

    完整路径可以压缩成：

    历史 latent Cache C
        │
当前 Q ─┴─> 吸收式 score → softmax P → P @ C
                                      │
                                      ▼
                              当前 latent context
                                      │ V 上投影
                                      ▼
                             多头输出 o_tilde
                                      │
当前 x_t ─> sigmoid(x_t @ W_G) ───────┤ 逐通道相乘
                                      ▼
                              output projection
                                      │
                                      ▼
                                     y_t

    最简洁的结论是：

    \[ \boxed{ \begin{aligned} &\text{MLA 用 latent Cache 高效地执行全局读取；}\\ &\text{Gate 用当前 token 动态筛选读出的通道；}\\ &\text{Cache 优势保留，但 V-up 与输出矩阵不能跨 gate 静态合并。} \end{aligned} } \]
