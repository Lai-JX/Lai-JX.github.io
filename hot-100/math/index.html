    算法题常用数学¶

    算法题中的“数学”通常不是考证明本身，而是要求先识别结构，再把问题化成可以高效计算的形式。常见目标包括：

    • 用数论性质减少枚举范围；
    • 用组合公式代替逐个计数；
    • 用代数变形消去绝对值、区间或重复计算；
    • 用期望、向量、矩阵等工具建立可递推的模型；
    • 明确公式的适用条件，避免取模、溢出和精度错误。

    本文以“识别信号 → 核心结论 → 常用模板 → 易错点”为主线，适合作为面试和刷题时的快速复习手册。

    快速复习¶

    题目中的信号 优先联想到 核心思想
    约数、倍数、互质、周期同步 GCD / LCM 欧几里得算法、质因数分解
    指数极大且要求取模 快速幂 按指数二进制拆分
    大量判断质数或分解小范围整数 筛法 一次预处理，多次查询
    方案数、选法、排列 组合数、容斥 避免重复或遗漏计数
    合法括号、栈序列、二叉树形态 卡特兰数 受约束路径计数

    1. 整数与数论¶

    1.1 最大公约数与最小公倍数¶

    欧几里得算法基于：

    \[ \gcd(a,b)=\gcd(b,a\bmod b) \]

    时间复杂度为 \(O(\log \min(|a|,|b|))\)。

    from math import gcd


def lcm(a: int, b: int) -> int:
    if a == 0 or b == 0:
        return 0
    # 先除后乘，在定长整数语言中可降低中间结果溢出的风险。
    return abs(a // gcd(a, b) * b)

    常用结论：

    • \(\gcd(a,b)\times\operatorname{lcm}(a,b)=|ab|\)，其中 \(a,b\) 均非零；
    • \(a,b\) 互质等价于 \(\gcd(a,b)=1\)；
    • 线性丢番图方程 \(ax+by=c\) 有整数解，当且仅当 \(\gcd(a,b)\mid c\)；
    • 多个周期第一次重新同步，常转化为求它们的 LCM。

    1.2 扩展欧几里得与乘法逆元¶

    扩展欧几里得算法可以求出 \(x,y\)，使得：

    \[ ax+by=\gcd(a,b) \]
    def exgcd(a: int, b: int) -> tuple[int, int, int]:
    """返回 (g, x, y)，满足 ax + by = g = gcd(a, b)。"""
    if b == 0:
        return abs(a), 1 if a >= 0 else -1, 0
    g, x1, y1 = exgcd(b, a % b)
    return g, y1, x1 - (a // b) * y1


def mod_inverse(a: int, m: int) -> int:
    g, x, _ = exgcd(a, m)
    if g != 1:
        raise ValueError("逆元不存在")
    return x % m

    \(a\) 在模 \(m\) 下存在乘法逆元，当且仅当 \(\gcd(a,m)=1\)。模数 \(p\) 为质数且 \(a\not\equiv0\pmod p\) 时，由费马小定理：

    \[ a^{-1}\equiv a^{p-2}\pmod p \]

    不要把“模意义下的除法”写成普通整数除法。\(a/b\pmod m\) 应写成 \(a\cdot b^{-1}\pmod m\)，并先确认 \(b\) 的逆元存在。

    1.3 模运算与快速幂¶

    对正模数 \(m\)：

    \[ (a+b)\bmod m=((a\bmod m)+(b\bmod m))\bmod m \]
    \[ ab\bmod m=((a\bmod m)(b\bmod m))\bmod m \]

    快速幂把指数按二进制拆分，可在 \(O(\log n)\) 时间内计算 \(a^n\bmod m\)。

    def quick_pow(base: int, exp: int, mod: int) -> int:
    if exp < 0:
        raise ValueError("此模板不处理负指数")
    ans = 1 % mod
    base %= mod
    while exp:
        if exp & 1:
            ans = ans * base % mod
        base = base * base % mod
        exp >>= 1
    return ans

    Python 在 \(m>0\) 时会让 x % m 落在 \([0,m)\)；C/C++ 中负数取模的结果可能为负，常用 (x % m + m) % m 归一化。

    1.4 质数、筛法与质因数分解¶

    单次判断 \(n\) 是否为质数，只需试除到 \(\sqrt n\)。如果要回答大量 \([1,n]\) 范围内的质数查询，应使用筛法。

    def eratosthenes(n: int) -> list[int]:
    if n < 2:
        return []

    is_prime = bytearray(b"\x01") * (n + 1)
    is_prime[0:2] = b"\x00\x00"

    p = 2
    while p * p <= n:
        if is_prime[p]:
            # 小于 p*p 的合数已被更小质因数筛掉。
            is_prime[p * p : n + 1 : p] = b"\x00" * (
                (n - p * p) // p + 1
            )
        p += 1

    return [x for x in range(2, n + 1) if is_prime[x]]
    • 埃氏筛时间复杂度约为 \(O(n\log\log n)\)；
    • 欧拉筛（线性筛）可以保证每个合数只被其最小质因数筛一次，复杂度为 \(O(n)\)；
    • 若还需要快速分解许多整数，可在筛法中同时记录最小质因数 spf[x]。

    算术基本定理说明，每个大于 \(1\) 的整数都能唯一写成：

    \[ n=\prod_{i=1}^{k}p_i^{e_i} \]

    由此可得正约数个数与正约数之和：

    \[ \tau(n)=\prod_{i=1}^{k}(e_i+1) \]
    \[ \sigma(n)=\prod_{i=1}^{k}(1+p_i+p_i^2+\cdots+p_i^{e_i}) \]

    试除分解时循环条件写成 p * p <= n；循环结束后若 n > 1，剩余的 n 本身是一个质因数。

    2. 组合数学与计数¶

    2.1 排列与组合¶

    从 \(n\) 个不同元素中有序地选 \(k\) 个：

    \[ A_n^k=\frac{n!}{(n-k)!} \]

    无序地选 \(k\) 个：

    \[ \binom nk=\frac{n!}{k!(n-k)!} \]

    常用恒等式：

    \[ \binom nk=\binom n{n-k} \]
    \[ \binom nk=\binom{n-1}{k-1}+\binom{n-1}{k} \]

    当模数 \(p\) 为质数，且预处理范围小于 \(p\) 时，可以预处理阶乘和逆阶乘，在 \(O(1)\) 时间查询组合数。

    def combination_table(n: int, p: int) -> tuple[list[int], list[int]]:
    """要求 p 为质数且 n < p。"""
    fact = [1] * (n + 1)
    for i in range(1, n + 1):
        fact[i] = fact[i - 1] * i % p

    inv_fact = [1] * (n + 1)
    inv_fact[n] = pow(fact[n], p - 2, p)
    for i in range(n, 0, -1):
        inv_fact[i - 1] = inv_fact[i] * i % p
    return fact, inv_fact


def comb(n: int, k: int, p: int, fact: list[int], inv_fact: list[int]) -> int:
    if k < 0 or k > n:
        return 0
    return fact[n] * inv_fact[k] % p * inv_fact[n - k] % p

    这里的 n < p 很重要：当 \(n\ge p\) 时，\(n!\equiv0\pmod p\)，不能直接对它求逆。若 \(p\) 较小且 \(n\) 很大，可以考虑 Lucas 定理：

    \[ \binom nk\equiv \prod_i\binom{n_i}{k_i}\pmod p \]

    其中 \(n_i,k_i\) 是 \(n,k\) 的 \(p\) 进制数位，且 \(p\) 必须是质数。

    2.2 容斥原理¶

    两个集合时：

    \[ |A\cup B|=|A|+|B|-|A\cap B| \]

    推广到多个集合：先加单集合，减两两交集，加三者交集，符号交替。容斥常用于：

    • 统计“至少满足一个条件”的对象；
    • 先计算全部方案，再排除非法方案；
    • 统计不被若干整数整除的数；
    • 配合状态压缩枚举条件子集。

    若有 \(k\) 个限制，直接枚举全部交集通常需要 \(O(2^k)\)，因此只适用于 \(k\) 较小的情况。

    2.3 卡特兰数¶

    第 \(n\) 个卡特兰数为：

    \[ C_n=\frac{1}{n+1}\binom{2n}{n} =\binom{2n}{n}-\binom{2n}{n+1} \]

    递推形式为：

    \[ C_{n+1}=\sum_{i=0}^{n}C_iC_{n-i},\qquad C_0=1 \]

    典型模型包括：

    • \(n\) 对合法括号序列；
    • \(n\) 个元素按固定入栈顺序产生的合法出栈序列；
    • \(n\) 个结点的不同二叉树形态；
    • 不越过对角线的格点路径。

    对组合公式取模时，除以 \(n+1\) 同样需要确认逆元存在；否则应改用不含除法的形式或专门的质因数方法。

    2.4 鸽巢原理¶

    将多于 \(n\) 个对象放进 \(n\) 个盒子，至少有一个盒子包含两个对象。它常被用于证明“某种情况必然存在”。

    一个常见变体是前缀和取模：若前缀余数中出现 \(0\)，或者两个前缀余数相同，它们之间的子数组和就能被模数整除。

    3. 位运算与集合表示¶

    位运算适合表达二值状态、奇偶性和小规模集合。

    表达式 含义
    x & 1 判断最低位，即整数奇偶性
    x & (x - 1) 删除最低位的一个 1
    x & -x 取最低位的一个 1（lowbit）
    (x >> i) & 1 读取第 i 位
    x | (1 << i) 将第 i 位置为 1
    x & ~(1 << i) 将第 i 位清零
    x ^ x 结果为 0

    判断正整数是否为 \(2\) 的幂：

    def is_power_of_two(x: int) -> bool:
    return x > 0 and (x & (x - 1)) == 0

    枚举 mask 的所有非空子集：

    subset = mask
while subset:
    # 使用 subset
    subset = (subset - 1) & mask
# 空集需要在循环外单独处理。

    若只有一个数出现奇数次、其他数均出现偶数次，将全部元素异或即可找出它。这个结论依赖出现次数条件；不能把异或当成任意“找不同”问题的通用解法。

    状态压缩 DP 通常用一个整数表示集合，状态数为 \(2^n\)，适合 \(n\) 较小的场景。除了时间复杂度，还要同时估算 2**n 个状态的内存开销。

    4. 代数变形与最值¶

    4.1 绝对值的两类经典模型¶

    绝对值可以写成：

    \[ |x|=\max(x,-x) \]

    距离和最小：取中位数¶

    对一维点 \(x_1,\ldots,x_n\)，函数

    \[ f(p)=\sum_{i=1}^{n}|x_i-p| \]

    在任意中位数处取得最小值。若每个点具有正权重，则对应结论是取加权中位数。

    这解决的是“距离之和最小”。如果目标是“最远距离最小”，模型和答案通常不同，不应混用。

    最大值最小：拆成两条直线¶

    考虑常见形式：

    \[ f(p)=\max_i\left(a_i+|i-p|\right) \]

    先对单项拆绝对值：

    \[ a_i+|i-p| =\max(a_i+i-p,\ a_i-i+p) \]

    再把与 \(p\) 无关的部分预处理：

    \[ A=\max_i(a_i+i),\qquad B=\max_i(a_i-i) \]

    于是：

    \[ f(p)=\max(A-p,\ B+p) \]

    前一项随 \(p\) 单调递减，后一项随 \(p\) 单调递增，所以 \(f\) 是凸的 V 形函数。连续域中的平衡点满足：

    \[ A-p=B+p \quad\Longrightarrow\quad p=\frac{A-B}{2} \]

    若 \(p\) 必须为整数且被限制在区间 \([L,R]\)，只需检查平衡点附近的两个整数以及必要的区间边界。

    def minimize_max_abs(a: list[int], left: int, right: int) -> tuple[int, int]:
    """最小化 max_i(a[i] + abs(i - p))，p 为 [left, right] 内整数。"""
    A = max(value + i for i, value in enumerate(a))
    B = max(value - i for i, value in enumerate(a))

    center = (A - B) // 2
    candidates = {
        left,
        right,
        max(left, min(right, center)),
        max(left, min(right, center + 1)),
    }

    def objective(p: int) -> int:
        return max(A - p, B + p)

    best_p = min(candidates, key=lambda p: (objective(p), p))
    return best_p, objective(best_p)

    这种方法的关键不是记住最终公式，而是识别出“若干一次函数的最大值”。此类函数通常具有凸性，可以检查交点、断点或用三分/二分寻找最优位置。

    4.2 常见不等式¶

    三角不等式：

    \[ |a+b|\le |a|+|b| \]

    均值不等式要求 \(a,b\ge0\)：

    \[ \frac{a+b}{2}\ge\sqrt{ab} \]

    等号在 \(a=b\) 时成立。它经常用于固定和求乘积最大值、固定积求和最小值，但使用前必须检查变量的非负性和约束范围。

    柯西不等式的常用形式：

    \[ \left(\sum_{i=1}^{n}a_i^2\right) \left(\sum_{i=1}^{n}b_i^2\right) \ge \left(\sum_{i=1}^{n}a_ib_i\right)^2 \]

    竞赛题中更重要的是知道等号条件，而不是只记不等号方向：上式等号成立于两个向量线性相关时。

    4.3 二分答案¶

    二分答案适用于“答案越大越容易满足”或“答案越小越容易满足”这类具有单调性的判定问题。

    寻找满足 check(x) == True 的最小整数：

    def first_true(left: int, right: int, check) -> int:
    """要求答案存在于闭区间 [left, right]。"""
    while left < right:
        mid = left + (right - left) // 2
        if check(mid):
            right = mid
        else:
            left = mid + 1
    return left

    二分前要依次确认：

    1. check 是否真的单调；
    2. 搜索区间是否覆盖答案；
    3. 循环不变量是“找第一个真”还是“找最后一个真”；
    4. 答案不存在时如何处理。

    5. 前缀和、差分与哈希计数¶

    5.1 一维前缀和¶

    令：

    \[ S_0=0,\qquad S_{i+1}=S_i+a_i \]

    则左闭右开区间 \([l,r)\) 的和为：

    \[ \sum_{i=l}^{r-1}a_i=S_r-S_l \]
    prefix = [0]
for value in nums:
    prefix.append(prefix[-1] + value)

interval_sum = prefix[right] - prefix[left]

    “和为 \(k\) 的子数组个数”可由 \(S_r-S_l=k\) 改写为 \(S_l=S_r-k\)，因此扫描右端点时用哈希表统计此前前缀和出现次数即可。

    5.2 二维前缀和¶

    若 pre[i][j] 表示左上角到 (i, j) 之前的矩形和，则矩形 \([x_1,x_2)\times[y_1,y_2)\) 的和为：

    \[ P(x_2,y_2)-P(x_1,y_2)-P(x_2,y_1)+P(x_1,y_1) \]

    其本质是二维容斥：两块多减的重叠区域需要加回来。

    5.3 差分¶

    差分数组记录相邻元素的变化：

    \[ d_0=a_0,\qquad d_i=a_i-a_{i-1} \]

    对闭区间 \([l,r]\) 全部加 \(x\)，只需：

    diff[left] += x
if right + 1 < len(diff):
    diff[right + 1] -= x

    最后对 diff 求前缀和即可还原修改后的数组。差分适合“多次区间修改，最后统一查询”；如果修改和查询在线交错，通常需要树状数组或线段树。

    6. 递推与矩阵快速幂¶

    只要递推关系是固定维度的线性变换，就可以写成：

    \[ \mathbf{s}_{n}=M\mathbf{s}_{n-1} \]

    进而得到：

    \[ \mathbf{s}_{n}=M^n\mathbf{s}_{0} \]

    例如斐波那契数列：

    \[ \begin{bmatrix} F_{n+1}\\ F_n \end{bmatrix} = \begin{bmatrix} 1&1\\ 1&0 \end{bmatrix} \begin{bmatrix} F_n\\ F_{n-1} \end{bmatrix} \]

    对矩阵做快速幂，可以在 \(O(k^3\log n)\) 时间计算 \(k\) 维线性递推的第 \(n\) 项。

    def mat_mul(a: list[list[int]], b: list[list[int]], mod: int) -> list[list[int]]:
    rows, inner, cols = len(a), len(b), len(b[0])
    result = [[0] * cols for _ in range(rows)]
    for i in range(rows):
        for k in range(inner):
            if a[i][k] == 0:
                continue
            for j in range(cols):
                result[i][j] = (result[i][j] + a[i][k] * b[k][j]) % mod
    return result


def mat_pow(matrix: list[list[int]], exp: int, mod: int) -> list[list[int]]:
    size = len(matrix)
    result = [[int(i == j) for j in range(size)] for i in range(size)]
    while exp:
        if exp & 1:
            result = mat_mul(result, matrix, mod)
        matrix = mat_mul(matrix, matrix, mod)
        exp >>= 1
    return result

    建模时最容易遗漏的是状态。若下一步不仅依赖前一项，还依赖常数、前缀和或更早的若干项，应把这些量一并放入状态向量。

    7. 概率与期望¶

    7.1 期望的线性性¶

    无论随机变量是否独立，都有：

    \[ \mathbb E[X+Y]=\mathbb E[X]+\mathbb E[Y] \]

    如果 \(X\) 表示满足条件的对象数量，可把它拆成指示变量：

    \[ X=I_1+I_2+\cdots+I_n \]

    因此：

    \[ \mathbb E[X]=\sum_{i=1}^{n}\Pr(I_i=1) \]

    这能绕过复杂的联合分布，常用于求逆序对、固定点、被覆盖点或碰撞数量的期望。

    注意：期望可直接相加不要求独立，但方差相加通常需要独立或协方差为零。

    7.2 条件期望与期望 DP¶

    根据第一次转移分类：

    \[ E(s)=c(s)+\sum_t P(s\to t)E(t) \]

    其中 \(c(s)\) 是当前一步的代价。若状态转移形成 DAG，可按逆拓扑顺序计算；若存在环，自依赖项必须移到等式另一侧，多个循环依赖状态可能需要解线性方程组。

    例如每次独立试验以概率 \(p\) 成功，则首次成功前的期望试验次数满足：

    \[ E=1+(1-p)E \quad\Longrightarrow\quad E=\frac1p \]

    7.3 随机数映射与拒绝采样¶

    把均匀随机源映射到另一个范围时，必须保证每个目标值拥有相同数量的原像。若源状态数不是目标状态数的整数倍，应舍弃多余状态后重试，这就是拒绝采样。

    性能分析不能只看一次尝试的成本。若每次尝试的接受率为 \(q\)，平均尝试次数为 \(1/q\)。

    8. 计算几何¶

    8.1 点积与叉积¶

    二维向量 \(\mathbf a=(a_x,a_y)\)、\(\mathbf b=(b_x,b_y)\) 的点积：

    \[ \mathbf a\cdot\mathbf b=a_xb_x+a_yb_y \]

    它可用于判断夹角、投影和垂直关系。

    二维叉积返回一个标量：

    \[ \mathbf a\times\mathbf b=a_xb_y-a_yb_x \]

    对三点 \(O,A,B\)，\(\overrightarrow{OA}\times\overrightarrow{OB}\)：

    • 大于 \(0\)：\(B\) 在向量 \(OA\) 左侧；
    • 小于 \(0\)：\(B\) 在右侧；
    • 等于 \(0\)：三点共线。
    def cross(o: tuple[int, int], a: tuple[int, int], b: tuple[int, int]) -> int:
    return (a[0] - o[0]) * (b[1] - o[1]) - (a[1] - o[1]) * (b[0] - o[0])

    整数坐标应尽量全程使用整数叉积，避免不必要的浮点误差。

    8.2 多边形面积与凸包¶

    按边界顺序给出多边形顶点 \((x_i,y_i)\)，鞋带公式为：

    \[ 2S=\left|\sum_{i=0}^{n-1} (x_i y_{i+1}-y_i x_{i+1})\right| \]

    下标按模 \(n\) 循环。保留两倍面积可以避免除以 \(2\) 引入浮点数。

    凸包是包含所有点的最小凸多边形。Andrew 单调链算法先排序，再分别构造上凸壳和下凸壳，复杂度为 \(O(n\log n)\)。实现时要先确定：共线边界点是全部保留，还是只保留端点；这会决定弹栈条件使用 < 0 还是 <= 0。

    9. 图论中的数学结构¶

    图论算法背后有一些经常用于判定和证明的不变量：

    • 无向图中所有顶点度数之和等于 \(2|E|\)；
    • 一棵含 \(n\) 个顶点的树恰有 \(n-1\) 条边；
    • 对无向图，任取“连通、无环、边数为 \(n-1\)”中的任意两个条件，通常可推出第三个；
    • 图是二分图，当且仅当它不存在奇环；
    • 有向图能完成拓扑排序，当且仅当它是 DAG；
    • 并查集维护的是等价关系：自反、对称、传递。

    这些结论常用于在写 BFS、DFS、拓扑排序或并查集之前，先缩小问题模型。

    10. 博弈论基础¶

    标准 Nim 游戏中有若干堆石子，两人轮流从一堆中取走任意个，无法行动者失败。设各堆大小为 \(a_1,\ldots,a_n\)，则当前状态为必败态，当且仅当：

    \[ a_1\oplus a_2\oplus\cdots\oplus a_n=0 \]

    更一般的有限、公平、无偏、正常规则组合游戏可以使用 SG 函数：

    \[ SG(x)=\operatorname{mex}\{SG(y)\mid x\to y\} \]

    其中 mex 表示集合中没有出现的最小非负整数。独立子游戏合并后的 SG 值是各子游戏 SG 值的异或和。

    Nim 的结论不能直接套到“双方可执行操作不同”“允许平局”或“最后行动者失败”等规则中，必须先检查游戏是否满足适用条件。

    11. 数据范围与复杂度¶

    数据范围只能帮助估计算法量级，不是绝对规则；还要考虑语言、常数、测试组数和内存限制。

    典型规模 候选思路
    \(n\le 20\) 回溯、状态压缩，约 \(O(2^n)\)
    \(n\le 40\) 折半搜索，约 \(O(2^{n/2})\)
    \(n\le 10^3\) 常见 \(O(n^2)\)，需关注常数
    \(n\le 10^5\) 或 \(2\times10^5\) 常见 \(O(n\log n)\) 或 \(O(n)\)
    \(n\le 10^6\) 通常需要近线性算法和紧凑内存
    数值上界约 \(10^9\) 单次 \(O(\sqrt n)\) 可能可行，多次查询需预处理
    指数或下标约 \(10^{18}\) \(O(\log n)\)：快速幂、矩阵快速幂、二分

    常见空间估算：

    • Python int 和对象容器的实际占用远大于数值位宽，不能按 4 或 8 字节简单估算；
    • \(2^{20}\approx10^6\)，状态压缩数组已经不小；
    • 二维 DP 若只依赖上一行，应考虑滚动数组；
    • 图的邻接矩阵是 \(O(n^2)\) 空间，稀疏图通常应使用邻接表。

    12. 高频易错点¶

    取模¶

    • 只有加法和乘法可以直接逐步取模；除法必须转化为乘逆元；
    • 逆元存在的条件是分母与模数互质；
    • 费马小定理求逆要求模数为质数；
    • 组合数阶乘逆元模板还通常要求预处理范围小于模数。

    整数与除法¶

    • 在定长整数语言中，乘法后取模仍可能先溢出；
    • 求 LCM 时先除以 GCD 再乘；
    • Python 的 // 向负无穷取整，C/C++ 整数除法向零截断；处理负数边界时结果可能不同；
    • 二分中使用 left + (right - left) // 2，并明确左右边界是否包含。

    浮点数¶

    • 不直接用 == 判断一般浮点计算结果；
    • 几何中的方向判断优先使用整数叉积；
    • 涉及金额、精确比例或取整边界时，优先推导整数公式；
    • 使用误差 eps 时，必须结合数值量级和题目允许误差，而不是机械固定为某个值。

    公式与边界¶

    • 写公式前先列出变量范围：是否允许 \(0\)、负数、空集；
    • 检查等号成立条件，它往往直接给出最优解；
    • 区分连续最优点与整数可行点；
    • 推导完成后至少验证最小规模、边界规模和一个手算样例。

    解题检查清单¶

    1. 题目是在计数、判定，还是优化某个目标？
    2. 是否存在整除、奇偶、对称、单调或凸性结构？
    3. 能否通过前缀量、差分量或变量代换消掉重复计算？
    4. 使用公式时，质数、互质、非负、独立等前提是否成立？
    5. 复杂度和内存是否与数据范围匹配？
    6. 是否存在溢出、负数取模、整数取整或浮点误差？
    7. 连续域推导出的答案，是否需要映射回整数或离散候选点？

    数学工具的价值不在于让代码显得短，而在于把原问题变成结构清楚、边界可控、复杂度可证明的新问题。

    笔试遇到的小知识点¶

    1. 独立随机变量方差性质：\(D(aX+bY)=a^2D(X) +b^2D(Y)\)
    2. PCA 基于方差进行降维，对尺度敏感，大量纲会主导协方差。投影值等于数据点向量与单位特征向量的内积
    3. 皮尔逊相关系数：它会先对数据做中心化（减去各自均值），消除用户评分尺度差异（比如有人习惯打高分、有人习惯打低分），只衡量变化趋势的相关性，适合用户评分尺度差异明显的场景。
    4. 困惑度是平均负对数似然的指数，越低表示更可预测。
    5. 任意实矩阵均可 SVD，奇异值非负。在奇异值分解（SVD）中，对角矩阵 Σ 上非零奇异值的个数正好等于原矩阵 A 的秩 rank(A)
    6. 混合精度训练中使用 FP16 存储梯度，其表示范围较小。在反向传播时，许多很小的梯度会下溢（变成 0），因此需要使用 loss scaling 将损失放大，使得梯度落在 FP16 的安全表示范围内。
    7. 贝叶斯公式：\(P(A|B)=\frac{P(AB)}{P(B)}=\frac{P(B|A)p(A)}{p(B)}\). \(P(B)=P(AB)P(\hat A B)\)
    8. 线性子空间的定义要求对向量加法和标量乘法封闭。取标量为 0 进行数乘，可知任何线性子空间必然包含零向量。
    9. Lagrange 与 Newton 插值：给定相同的 n+1 个互异数据点，次数不超过 n 且通过全部节点的插值多项式唯一（因此二者的结果一致）。Newton 形式更便于增量加入节点

    线性代数¶

    • 矩阵的秩：通过将矩阵化为行阶梯式，有多少个非全0的行，秩就是多少
    • 向量组线性相关：某个向量可以由其余向量组成
      • 线性相关：有“大哥”可以由“小弟”（基向量）组成
      • 线性无关：全是“小弟”，没有“大哥”
      • 小弟数=向量组的秩，所以说不满秩的时候就是线性相关的
      • 某个向量加入向量组前后，向量组的秩不变，说明加入的向量是“大哥”，该向量可以由原本的向量组线性表示
    • 向量组的极大无关组：求秩后，每行第一个非0数所在的列，对应的向量

    • 判断方程组解的情况：

      1. 求秩
      2. 判断有无反常情况（如0=1），若有则无解；若没有，则 秩（有效式子数）= 未知数个数：有一组解 秩（有效式子数）< 未知数个数：有无穷多组解
      3. 对于齐次方程组（等式右边全为0）：一定有解（零解）
      4. 对于非齐次方程组

    • 行最简型：1. 得到行阶梯矩阵；2. 使每行首个非0数为1；3. 使每个首个非0数所在列里，其余数都是0

    • 行最简型的作用：

      • 用极大无关组表示向量
      • 求方程组通解
      • 求矩阵的逆矩阵

    • 求行列式：将矩阵转化为下三角全为0的矩阵，然后行列式为对角线元素相乘

      • 某行（列）的公因子可以提到||外
      • 某行（列）= 本身 - k*其他行（列）
      • 交换行（列）与行（列），||前乘(-1)
    • 行列式的作用
      • 行列式非0时可逆
      • 求矩阵的特征值: \(|A-\lambda E|=0\)
    • 特征值和特征向量
      • 求对角矩阵和可逆矩阵：\(P^{-1}AP=\Lambda\) (P由特征向量的基组成，\(\Lambda\) 由特征值组成)
      • 求对角矩阵和正交矩阵：\(Q^{T}AQ=\Lambda\) (Q由特征向量的基组成（同时保证单位且正交），\(\Lambda\) 由特征值组成)
      • 求二次型的标准型和正交变换
    \[ \det(A) \neq 0 \iff A \text{可逆} \iff A \text{满秩}(r=n) \iff \text{列向量线性无关} \iff Ax=0 \text{只有零解} \]
