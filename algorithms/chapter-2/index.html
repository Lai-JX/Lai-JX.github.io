    复习提示

    链表的一大问题就是操作当前节点必须要找前一个节点才能操作。这就造成了，头结点的尴尬，因为头结点没有前一个节点了。

    每次对应头结点的情况都要单独处理，所以使用虚拟头结点的技巧，就可以解决这个问题。

    涉及到对头节点进行操作的（删除、修改头节点的next等），均采用虚拟头节点的方法比较容易

    链表中采用双指针一般是为了对齐，方便定位

    2.1 移除元素

    • 由于头节点没有上一个节点，其删除方式与正常节点不太一样，可以有两种方法：
      1. 删除前先用一个循环，删除头节点，直至头节点不等于目标值
      2. 新设一个虚拟头节点（dummy_head）
        1. 如果cur_head.next.val == val : cur_head.next = cur_head.next.next
        2. 否则：cur_head = cur_head.next
        3. 注意：dummy_head是没有物理意义的，不应该赋值具体的节点给他

    203.移除链表元素¶

    详细题解¶

    • 由于头节点没有上一个节点，其删除方式与正常节点不太一样，可以有两种方法：
      1. 删除前先用一个循环，删除头节点，直至头节点不等于目标值
      2. 新设一个虚拟头节点（dummy_head）
        1. 如果cur_head.next.val == val : cur_head.next = cur_head.next.next
        2. 否则：cur_head = cur_head.next
        3. 注意：dummy_head是没有物理意义的，不应该赋值具体的节点给他

    Python 实现¶

    # Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
class Solution:
    def removeElements(self, head: Optional[ListNode], val: int) -> Optional[ListNode]:
        # 创建虚拟头部节点以简化删除过程
        dummy_head = ListNode(next = head)

        # 遍历列表并删除值为val的节点
        current = dummy_head
        while current.next:
            if current.next.val == val:
                current.next = current.next.next
            else:
                current = current.next

        return dummy_head.next

    详细题解¶

    • 可以用一个类成员size来记录链表长度
    • addAtHead、addAtTail其实就是addAtIndex的特殊情况

    Python 实现¶

    class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class MyLinkedList:
    def __init__(self):
        self.dummy_head = ListNode()
        self.size = 0

    def get(self, index: int) -> int:
        if index < 0 or index >= self.size:
            return -1

        current = self.dummy_head.next
        for i in range(index):
            current = current.next

        return current.val

    def addAtHead(self, val: int) -> None:
        self.dummy_head.next = ListNode(val, self.dummy_head.next)
        self.size += 1

    def addAtTail(self, val: int) -> None:
        current = self.dummy_head
        while current.next:
            current = current.next
        current.next = ListNode(val)
        self.size += 1

    def addAtIndex(self, index: int, val: int) -> None:
        if index < 0 or index > self.size:
            return

        current = self.dummy_head
        for i in range(index):
            current = current.next
        current.next = ListNode(val, current.next)
        self.size += 1

    def deleteAtIndex(self, index: int) -> None:
        if index < 0 or index >= self.size:
            return

        current = self.dummy_head
        for i in range(index):
            current = current.next
        current.next = current.next.next
        self.size -= 1

    详细题解¶

    补充思路： 链表题的核心是维护节点关系。涉及头节点修改时优先引入虚拟头节点，涉及位置对齐时使用快慢指针。

    Python 实现¶

    # Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
class Solution:
    def reverseList(self, head: ListNode) -> ListNode:
        return self.reverse(head, None)
    def reverse(self, cur: ListNode, pre: ListNode) -> ListNode:
        if cur == None:
            return pre
        temp = cur.next
        cur.next = pre
        return self.reverse(temp, cur)

    24. 两两交换链表中的节点¶

    Unknown 打开原题 代码随想录

    快速复习¶

    先保存 next 再改指针；返回 dummy.next；画出三个连续节点。

    详细题解¶

    补充思路： 链表题的核心是维护节点关系。涉及头节点修改时优先引入虚拟头节点，涉及位置对齐时使用快慢指针。

    Python 实现¶

    # 递归版本
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next

class Solution:
    def swapPairs(self, head: Optional[ListNode]) -> Optional[ListNode]:
        if head is None or head.next is None:
            return head

        # 待翻转的两个node分别是pre和cur
        pre = head
        cur = head.next
        next = head.next.next

        cur.next = pre  # 交换
        pre.next = self.swapPairs(next) # 将以next为head的后续链表两两交换

        return cur

    19.删除链表的倒数第N个节点¶

    Unknown 打开原题 代码随想录

    快速复习¶

    采用双指针 - 快指针先走n步，接着快慢指针一起走；当快指针到达最后一个节点时，慢指针指向要删除的节点

    详细题解¶

    • 采用双指针
      • 快指针先走n步，接着快慢指针一起走。当快指针到达最后一个节点时，慢指针指向要删除的节点

    Python 实现¶

    # Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next

class Solution:
    def removeNthFromEnd(self, head: ListNode, n: int) -> ListNode:
        # 创建一个虚拟节点，并将其下一个指针设置为链表的头部
        dummy_head = ListNode(0, head)

        # 创建两个指针，慢指针和快指针，并将它们初始化为虚拟节点
        slow = fast = dummy_head

        # 快指针比慢指针快 n+1 步
        for i in range(n+1):
            fast = fast.next

        # 移动两个指针，直到快速指针到达链表的末尾
        while fast:
            slow = slow.next
            fast = fast.next

        # 通过更新第 (n-1) 个节点的 next 指针删除第 n 个节点
        slow.next = slow.next.next

        return dummy_head.next

    面试题 02.07. 链表相交¶

    Unknown 打开原题 代码随想录

    快速复习¶

    利用差或和的方式，减少遍历次数 - 先遍历两个链表，得到长度 - 计算长度差diff - 长的先走diff步 - 两个链表一同遍历直至相交

    详细题解¶

    利用差或和的方式，减少遍历次数

    • 先遍历两个链表，得到长度
    • 计算长度差diff
    • 长的先走diff步
    • 两个链表一同遍历直至相交

    Python 实现¶

    class Solution:
    def getIntersectionNode(self, headA: ListNode, headB: ListNode) -> ListNode:
        lenA, lenB = 0, 0
        cur = headA
        while cur:         # 求链表A的长度
            cur = cur.next 
            lenA += 1
        cur = headB 
        while cur:         # 求链表B的长度
            cur = cur.next 
            lenB += 1
        curA, curB = headA, headB
        if lenA > lenB:     # 让curB为最长链表的头，lenB为其长度
            curA, curB = curB, curA
            lenA, lenB = lenB, lenA 
        for _ in range(lenB - lenA):  # 让curA和curB在同一起点上（末尾位置对齐）
            curB = curB.next 
        while curA:         #  遍历curA 和 curB，遇到相同则直接返回
            if curA == curB:
                return curA
            else:
                curA = curA.next 
                curB = curB.next
        return None

    142.环形链表II¶

    Unknown 打开原题 代码随想录

    快速复习¶

    fast走两步，slow走一步；那么必定会在fast绕一圈后相遇（fast绕一圈） - \((x+y)2=x+n(y+z)+y\) - \(n=1\)：\(x=z\) - \(n1\)：\(x=(n-1)(y+z)+z\) - 所以只需找到相遇节点，然后同时从相遇节点和头节点遍历直至相交，相交节点即为入口节点

    详细题解¶

    • fast走两步，slow走一步。那么必定会在fast绕一圈后相遇（fast绕一圈）
    • \((x+y)*2=x+n*(y+z)+y\)
      • \(n=1\)：\(x=z\)
      • \(n>1\)：\(x=(n-1)(y+z)+z\)
    • 所以只需找到相遇节点，然后同时从相遇节点和头节点遍历直至相交，相交节点即为入口节点

    Python 实现¶

    # Definition for singly-linked list.
# class ListNode:
#     def __init__(self, x):
#         self.val = x
#         self.next = None


class Solution:
    def detectCycle(self, head: ListNode) -> ListNode:
        visited = set()

        while head:
            if head in visited:
                return head
            visited.add(head)
            head = head.next

        return None
