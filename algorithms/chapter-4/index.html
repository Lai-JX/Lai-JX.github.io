    344. 反转字符串¶

    Easy 打开原题 代码随想录

    快速复习¶
    1. 反转字符串 - 力扣（LeetCode） 采用双指针：s[i], s[s_len-i-1] = s[s_len-i-1], s[i]
    详细题解¶

    采用双指针：s[i], s[s_len-i-1] = s[s_len-i-1], s[i]

    Python 实现¶
    class Solution:
    def reverseString(self, s: List[str]) -> None:
        """
        Do not return anything, modify s in-place instead.
        """
        s[:] = reversed(s)

    详细题解¶

    同样很简单，但需要注意的是字符串是不可变对象（immutable），不能通过切片赋值进行原地修改

    Python 实现¶
    class Solution:
    def reverseStr(self, s: str, k: int) -> str:
        # Two pointers. Another is inside the loop.
        p = 0
        while p < len(s):
            p2 = p + k
            # Written in this could be more pythonic.
            s = s[:p] + s[p: p2][::-1] + s[p2:]
            p = p + 2 * k
        return s

    替换数字¶

    Unknown 打开原题 代码随想录

    快速复习¶

    不要在循环中反复拼接长字符串；使用列表加 ''.join() 保持线性复杂度。

    详细题解¶

    扫描字符串，数字字符写入 number，其他字符原样写入。Python 字符串不可变，使用列表收集后一次拼接。

    Python 实现¶
    # ACM 模式：把字符串中的每个数字字符替换为 "number"
def solve():
    text = input().strip()
    print(''.join('number' if ch.isdigit() else ch for ch in text))

if __name__ == "__main__":
    solve()

    151.翻转字符串里的单词¶

    Unknown 打开原题 代码随想录

    快速复习¶

    面试手写原地版本时记住三步：去空格、整体反转、局部反转。

    详细题解¶

    先清理首尾和单词间多余空格，再整体反转，最后逐个反转单词；Python 也可以分词后逆序拼接。

    Python 实现¶
    class Solution:
    def reverseWords(self, s):
        words = s.split() #type(words) --- list
        words = words[::-1] # 反转单词
        return ' '.join(words) #列表转换成字符串

    右旋字符串¶

    Unknown 打开原题 代码随想录

    快速复习¶

    先令 k %= n；Python 字符串不可变，切片会使用额外空间。

    详细题解¶

    把字符串在 n-k 处分成两段，结果是后段加前段；原地语言可通过整体反转和两段局部反转完成。

    Python 实现¶
    #获取输入的数字k和字符串
k = int(input())
s = input()

#通过切片反转第一段和第二段字符串
#注意：python中字符串是不可变的，所以也需要额外空间
s = s[len(s)-k:] + s[:len(s)-k]
print(s)

    4.5 重复的子字符串¶

    充分条件：如果字符串s是由重复子串组成，那么 最长相等前后缀不包含的子串 一定是 s的最小重复子串。

    必要条件：如果字符串s的最长相等前后缀不包含的子串 是 s最小重复子串，那么 s是由重复子串组成。

    在必要条件，这个是 显而易见的，都已经假设 最长相等前后缀不包含的子串 是 s的最小重复子串了，那s必然是重复子串。

    关键是需要证明， 字符串s的最长相等前后缀不包含的子串 什么时候才是 s最小重复子串。

    同上我们证明了，当 最长相等前后缀不包含的子串的长度 可以被 字符串s的长度整除，那么不包含的子串 就是s的最小重复子串。

    注：需先判断最长相等前后缀存在，再进行整除判断

    459. 重复的子字符串¶

    Easy 打开原题 代码随想录

    快速复习¶

    若存在非零最长相等前后缀，且 n 能被 n-next[-1] 整除，则由重复子串构成。

    详细题解¶

    充分条件：如果字符串s是由重复子串组成，那么 最长相等前后缀不包含的子串 一定是 s的最小重复子串。

    必要条件：如果字符串s的最长相等前后缀不包含的子串 是 s最小重复子串，那么 s是由重复子串组成。

    在必要条件，这个是 显而易见的，都已经假设 最长相等前后缀不包含的子串 是 s的最小重复子串了，那s必然是重复子串。

    关键是需要证明， 字符串s的最长相等前后缀不包含的子串 什么时候才是 s最小重复子串。

    同上我们证明了，当 最长相等前后缀不包含的子串的长度 可以被 字符串s的长度整除，那么不包含的子串 就是s的最小重复子串。

    注：需先判断最长相等前后缀存在，再进行整除判断

    Python 实现¶
    class Solution:
    def repeatedSubstringPattern(self, s: str) -> bool:
        n = len(s)
        if n <= 1:
            return False
        ss = s[1:] + s[:-1] 
        print(ss.find(s))              
        return ss.find(s) != -1
