    6.1 二叉树的遍历方式¶

    （1）递归遍历

    （2）迭代遍历

    本质还是利用栈的特性，使得遍历完某个子树之后能回到另一棵子树继续遍历

    • 前序遍历（处理节点为当前节点）：先处理当前节点，然后将右孩子加入栈，再将左孩子加入栈。
      • 先加右孩子的原因是：保证先遍历左子树（左孩子先出栈）
    • 中序遍历（处理节点不是当前节点）：
      • 当前节点不为空则一直向左孩子查询，不断入栈
      • 当前节点为空，说明栈顶节点没有左孩子，处理栈顶节点，并将其右孩子更新为当前节点
    • 后续遍历：可以借鉴前序遍历的代码，先处理当前节点，然后将左孩子加入栈，再将右孩子加入栈。这样遍历的结果是“中右左”，对结果reverse一下，变为“左右中”就是所求结果了

    上述几种遍历方式的实现方式无法统一的根源在于：当前访问节点并不一定是要打印的节点（节点不一定要在首次访问到时打印）

    解决方法：将访问的节点放入栈中，把要处理的节点也放入栈中但是要做标记。相当于在保证出栈的顺序是正确的，然后在出栈时处理节点

    （3）层序遍历

    在遍历时需要注意提前获取每层需要遍历的个数，因为队列长度是实时变化的

    - 和层序遍历一样，不过得在返回时进行reverse
- 在层序遍历时，判断是否为一层的最后一个节点，是的话就记录起来
- 加入队列时不是加入2个节点，而是加入N个节点
- 和上一题没区别
- 最简单的方法是采用层序遍历，如果采用后序遍历（如104），则必须区分只有一个孩子的情况

    详细题解¶

    在遍历时需要注意提前获取每层需要遍历的个数，因为队列长度是实时变化的

    补充思路： 先判断递归函数的返回值代表什么，再确定前序、中序还是后序处理；按层统计时使用队列。

    Python 实现¶
    # LeetCode 429. N-ary Tree Level Order Traversal
# 递归法
class Solution:
    def levelOrder(self, root: 'Node') -> List[List[int]]:
        if not root: return []
        result=[]
        def traversal(root,depth):
            if len(result)==depth:result.append([])
            result[depth].append(root.val)
            if root.children:
                for i in range(len(root.children)):traversal(root.children[i],depth+1)

        traversal(root,0)
        return result

    Python 实现¶
    # Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def invertTree(self, root: TreeNode) -> TreeNode:
        if not root:
            return None
        root.left, root.right = root.right, root.left
        self.invertTree(root.left)
        self.invertTree(root.right)
        return root

    Python 实现¶
    class Solution:
    def isSymmetric(self, root: TreeNode) -> bool:
        if not root:
            return True
        st = [] #这里改成了栈
        st.append(root.left)
        st.append(root.right)
        while st:
            rightNode = st.pop()
            leftNode = st.pop()
            if not leftNode and not rightNode:
                continue
            if not leftNode or not rightNode or leftNode.val != rightNode.val:
                return False
            st.append(leftNode.left)
            st.append(rightNode.right)
            st.append(leftNode.right)
            st.append(rightNode.left)
        return True

    110. 平衡二叉树¶

    Easy 打开原题 代码随想录

    快速复习¶

    后序返回高度；任一子树不平衡就用 -1 向上传播，避免重复计算高度。

    详细题解¶

    递归获取左子树和右子树的高度，再比较左子树和右子树的高度差。

    • 用-1标志以该节点为根的树不是平衡二叉树。后续如果发现子树的高度为-1，则直接传递上去
    • 可以看到，这里是先递归孩子节点，再进行处理。即后序遍历
    Python 实现¶
    class Solution:
    def isBalanced(self, root: Optional[TreeNode]) -> bool:
        return self.get_hight(root) != -1
    def get_hight(self, node):
        if not node:
            return 0
        left = self.get_hight(node.left)
        right = self.get_hight(node.right)
        if left == -1 or right == -1 or abs(left - right) > 1:
            return -1
        return max(left, right) + 1

    class Solution:

    def binaryTreePaths(self, root: TreeNode) -> List[str]:
        # 题目中节点数至少为1
        stack, path_st, result = [root], [str(root.val)], []

        while stack:
            cur = stack.pop()

    class Solution:
    def buildTree(self, preorder: List[int], inorder: List[int]) -> TreeNode:
        # 第一步: 特殊情况讨论: 树为空. 或者说是递归终止条件
        if not preorder:
            return None

        # 第二步: 前序遍历的第一个就是当前的中间节点.
        root_val = preorder[0]
        root = TreeNode(root_val)

        # 第三步: 找切割点.
        separator_idx = inorder.index(root_val)

        # 第四步: 切割inorder数组. 得到inorder数组的左,右半边.
        inorder_left = inorder[:separator_idx]
        inorder_right = inorder[separator_idx + 1:]

        # 第五步: 切割preorder数组. 得到preorder数组的左,右半边.
        # ⭐️ 重点1: 中序数组大小一定跟前序数组大小是相同的.
        preorder_left = preorder[1:1 + len(inorder_left)]
        preorder_right = preorder[1 + len(inorder_left):]

        # 第六步: 递归
        root.left = self.buildTree(preorder_left, inorder_left)
        root.right = self.buildTree(preorder_right, inorder_right)
        # 第七步: 返回答案
        return root

    236. 二叉树的最近公共祖先¶

    Medium 打开原题 代码随想录

    快速复习¶

    采用后序遍历的方法，从底向上遍历 - 遇到p、q时直接返回对应节点；- 否则进行后序遍历 - 当left和right均不为空时，返回当前节点，否则返回非空的节点

    详细题解¶

    采用后序遍历的方法，从底向上遍历

    - 遇到p、q时直接返回对应节点。
- 否则进行后序遍历
    - 当left和right均不为空时，返回当前节点，否则返回非空的节点
    Python 实现¶
    class Solution:
    def lowestCommonAncestor(self, root, p, q):
        if root == q or root == p or root is None:
            return root

        left = self.lowestCommonAncestor(root.left, p, q)
        right = self.lowestCommonAncestor(root.right, p, q)

        if left is not None and right is not None:
            return root

        if left is None:
            return right
        return left

    235. 二叉搜索树的最近公共祖先¶

    Medium 打开原题 代码随想录

    快速复习¶

    不用使用回溯，二叉搜索树自带方向性，可以方便的从上向下查找目标区间，遇到目标区间内的节点，直接返回

    详细题解¶
    • 不用使用回溯，二叉搜索树自带方向性，可以方便的从上向下查找目标区间，遇到目标区间内的节点，直接返回。
    Python 实现¶
    class Solution:
    def lowestCommonAncestor(self, root, p, q):
        if root.val > p.val and root.val > q.val:
            return self.lowestCommonAncestor(root.left, p, q)
        elif root.val < p.val and root.val < q.val:
            return self.lowestCommonAncestor(root.right, p, q)
        else:
            return root
